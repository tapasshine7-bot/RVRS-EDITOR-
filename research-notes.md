# REVRSE EDITOR Research Notes

## Movie discovery source

The Movie Dialogue Workspace uses the [Apple iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/Searching.html) only for factual movie discovery. Apple documents a `search` endpoint with a URL-encoded `term`, `country`, and `media=movie`, returning JSON metadata and store links. The service is rate-limited to approximately 20 requests per minute, so the server procedure limits results and the interface does not download, proxy, re-host, or extract movie files or dialogue.

## Rights-aware music discovery provider

REVRSE EDITOR will use the official [Jamendo developer platform](https://developer.jamendo.com/v3.0) as an optional catalog-discovery connection rather than shipping, copying, or redistributing a music catalogue. Jamendo documents catalog search and OAuth2-based account access; the developer portal is where a project obtains its own application credentials. The editor will show title, artist, duration, licence/source details, and provider link, and only permits adding a track after the creator acknowledges that they have checked the relevant Jamendo or licence terms for their planned use. It will neither autoplay, download, proxy, nor store catalog audio bytes. The connection is deliberately disabled until an application credential is supplied, because credentials are provider-specific and must never be invented or embedded in source code.

## Full-library provider boundary

The Jamendo developer portal states that its API supports catalog search and app integrations, while its sign-up information describes free API use as non-commercial and directs other commercial uses to the provider. REVRSE EDITOR must therefore keep the current Jamendo route metadata-only unless an appropriate commercial agreement expressly authorizes further use. The editor must not infer download, caching, redistribution, or end-user sublicensing rights from discovery access alone.

Epidemic Sound’s partner documentation is a useful example of what a genuine in-product catalog agreement looks like: it states that access requires a partnership agreement, defines the available collections or full catalogue in that agreement, documents user licensing tiers, and disallows partners from locally caching collection or track metadata. If REVRSE EDITOR ever pursues a commercial catalog partner, it should require comparable written terms, secure server-side credentials, provider-delivered audio, a rights-aware user entitlement, and no uncontrolled media copying.

Pixabay’s license summary allows use and adaptation subject to restrictions but prohibits selling or distributing content on a standalone basis. It is therefore not a source for a downloadable REVRSE EDITOR music catalogue. It may only be considered for links or creative-use workflows that continue to respect each item’s terms and any extra rights.

## B2B catalogue option: Feed.fm

Feed.fm’s official product pages describe **Feed Clips** as an API for licensed 60-second clips in video, animation, user-generated-content, and creative tools; it uses signed URLs, limited caching, and event tracking for reporting. Its **Feed Radio** offering is for full-length curated background-music streaming rather than editor downloads. The provider separately describes Feed Originals as a potentially downloadable/syncable catalogue, but access is commercial and must be governed by a provider agreement. Feed.fm’s published standard terms make clear that API access is contractual through a statement of work, may require end users to accept terms that limit their content rights, and can include geo-filtering. Accordingly, Feed.fm could be a future partner candidate for an in-editor clip workflow, but **REVRSE EDITOR must not integrate, cache, download, or present its catalogue as available until a written agreement confirms the exact catalogue, territories, editing/export rights, reporting events, and user-facing terms**. Sources: https://www.feed.fm/music-api and https://www.feed.fm/terms-and-conditions.

## B2B catalogue option: Mubert

Mubert’s official API pages describe a creator-tool product that can generate music from text, images, BPM, genre, and activity, and can expose a curated library filtered by genre, mood, activity, or BPM. Its official API licensing article distinguishes a platform licence (for in-app playback) from a downstream **sublicence** (for users exporting a video that contains the music or posting it externally). The article states that export/public-posting sublicensing is available only on **Startup+ or above**, while the Trial tier is for testing and the Startup tier is for in-app audio without user export rights. It also identifies prohibited uses across plans, including delivery through music-streaming services or stock-music platforms and Content ID registration. Mubert is therefore a potentially suitable future partner for REVRSE EDITOR’s exported-video workflow, but only after the owner purchases or contracts for a qualifying plan, receives credentials securely, and implements provider-required user tokens, licensing records, quotas, and use restrictions. Sources: https://mubert.com/api, https://mubert.com/api/use-cases/developers, and https://mubert.com/blog/mubert-api-sublicensing-the-hidden-truth-every-developer-must-know.

## B2B catalogue option: Soundstripe

Soundstripe’s official API page describes a partner API with search, metadata, streaming previews, and downloads, with licensing handled at the API layer. Its API terms require clients to serve library media from Soundstripe’s CDN, prohibit permanent downloading/caching/long-term storage unless expressly approved, require end users to agree to the provider terms, and make the platform responsible for authentication, monitoring, records, download counts, and reporting unauthorized use. The terms explicitly contemplate editor “Projects”: users may use the library media in combination with their own work and can distribute compliant projects, but the platform itself must not transfer ownership of the music or allow standalone redistribution. Soundstripe therefore appears to be the strongest currently documented candidate for REVRSE EDITOR’s eventual in-product searchable/downloadable library, but only under an executed production agreement with implemented authentication, auditable usage records, CDN-direct delivery, appropriate user terms, and supplier-approved quota management. Sources: https://www.soundstripe.com/api and https://www.soundstripe.com/api-terms-of-use.
